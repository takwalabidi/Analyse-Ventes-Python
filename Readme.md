##  Contexte du Projet
>Ce projet vise à remplacer la gestion manuelle sur tableur (Excel) par une solution automatisée en Python. Il permet de gérer de gros volumes de données, de calculer les indicateurs de rentabilité et de générer des rapports précis pour une entreprise d'e-commerce.

##  Travail Réalisé
>Le script exécute les étapes suivantes :
1. **Génération de données** : Création du fichier source `ventes.csv`.
2. **Calculs financiers** :
   * **CA Brut** : $Prix \times Quantité$
   * **CA Net** : Après application des remises (en %).
   * **TVA** : Calcul de la taxe de 20% sur le CA Net.
3. **Analyse** : Identification automatique du produit le plus rentable.
4. **Export** : Génération d'un fichier enrichi `resultats_final.csv`.

## Bonus Implémentés
>* **Visualisation** : Utilisation de **Matplotlib** pour générer des graphiques du CA par produit.
>* **Flexibilité** : Lecture dynamique pour supporter des fichiers CSV de tailles différentes.

## Technologies
>* **Langage** : Python 3
>* **Outils** : VS Code, Matplotlib
>* **Format** : CSV (Comma Separated Values)
